# Bitacora semana 01

## PRUEBA
 ## 1. Inicio del programa
 > Se crea una función llamada main(), que contiene las instrucciones principales. Al comenzar, el programa muestra el nombre del proyecto y un mensaje indicando que es la primera versión.
 ## 2. Ingreso del identificador 
 > El programa le pide al usuario que escriba un identificador del registro. Este identificador sirve para saber a qué registro pertenece la información
 ## 3. Ingreso del valor 
 > Después, solicita al usuario que introduzca un valor numérico. El valor se convierte a un número decimal usando float.
 ## 4. Clasificacion del registro 
 >El programa utiliza una regla muy sencilla: Si el valor es mayor o igual a 50, se clasifica como “ALTO”. Si el valor es menor de 50, se clasifica como “NORMAL”.
 ## 5. Mostrar el resultado 
 >Finalmente, el programa muestra: El identificador del registro. El valor que ingresó el usuario. La clasificación obtenida.
